# 읽기용 회의록

팀 회의 기록의 기준이 되는 읽기용 회의록을 보관합니다. 파일 이름은 `YYYY-MM-DD-주제.md`로 하고, 연도와 월 폴더 아래에 둡니다. 전사나 초안이 Notion에서 시작되면 해당 페이지 링크와 가져온 날짜를 기록하고, Git에 옮겨 검토한 뒤 기준 기록으로 관리합니다. Git에서 정리한 회의록을 Notion에 반영한 경우에도 읽기용 페이지 링크를 기록합니다.

회의록은 [템플릿](../templates/meeting.md)을 사용합니다. 같은 회의의 전사 원문은 `sources/meetings/YYYY/MM/YYYY-MM-DD.md`에 별도로 둡니다. 회의록 상단에 원문 경로를 적고, 관련 결정·피드백에는 전사 시간표시를 연결합니다.

요약은 먼저 한눈에 읽히게 작성하고, 결정은 상태를 구분합니다. 참석자가 핵심 사실을 검토한 뒤에만 `confirmed`로 표시합니다. 교수님이나 외부 대표의 피드백은 제공자, 발언일, 출처, 팀의 대응을 나눠 씁니다.

회의록 공유 Slack 메시지에는 확인된 요약, 확정된 결정, 할 일, 읽기용 Notion 페이지 링크를 담습니다. 두 저장 위치의 내용이 다르면 검토 후 Git 기준 기록을 맞추고 Notion을 갱신합니다.
